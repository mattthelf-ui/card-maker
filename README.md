# Hockey Card Maker

Make a premium hockey card in 7 easy steps: upload a cut-out photo, place it, pick a background, border, text and effect, then get a premium render (hi-res PNG front/back, animated holo preview, print-ready PDF with bleed and crop marks).

Installable web app, works offline after first load. Live: https://mattthelf-ui.github.io/card-maker/
